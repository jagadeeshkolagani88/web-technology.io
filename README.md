# CodeSphere – JavaScript Practicals

## 📚 About the Project

This folder contains **67 JavaScript practical programs** designed for learning and practicing JavaScript programming.

Each practical is provided as a separate HTML file with:

* HTML
* CSS
* JavaScript
* Interactive input and output
* CodeSphere-themed user interface

The practicals can be opened directly in a web browser without requiring any additional software.

## 🚀 How to Run

### Method 1 – Open Directly

1. Open the `javascript` folder.
2. Double-click `index.html`.
3. Select any practical.
4. Enter the required input.
5. Click the button to execute the program.

### Method 2 – Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open the `javascript` folder.
3. Open `index.html`.
4. Run it using a browser or the **Live Server** extension.
5. Select the required practical from the practical list.
